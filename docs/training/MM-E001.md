# MM-E001 — First Real Pretraining

## Purpose

Prove that MM-0A can learn coherent language from a provenance-tracked real-text corpus before
mesh-specific architecture changes begin.

## Corpus

The initial controlled corpus is TinyStories. Its dataset card declares CDLA-Sharing-1.0 and
describes synthetic stories generated by GPT-3.5 and GPT-4. The acquisition script downloads a
specific split and prints its SHA-256. Training is forbidden until that hash replaces the manifest
placeholder.

TinyStories is a research control corpus, not the intended final MeshMind knowledge mixture.

## Tokenizer

Train MeshMind's byte-level BPE from corpus text with a target vocabulary of 16,384 tokens.
Benchmark it against the lossless byte tokenizer for:

- encoded bytes per token
- tokens per character
- round-trip correctness
- code and Unicode behavior
- tokenizer model size

## Reproducibility

Every run records model configuration, training configuration, seed, dataset hash, tokenizer
artifact, metrics JSONL, and checkpoints. Checkpoints include optimizer and RNG state so interrupted
runs can resume rather than restart.

## Success gate

MM-E001 passes when validation loss falls reproducibly and generated samples demonstrate that the
model has learned nontrivial corpus structure. Perplexity, tokens processed, wall-clock time, peak
memory, and checkpoint identity must be recorded before MM-0B begins.
